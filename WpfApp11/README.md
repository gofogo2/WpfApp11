# WpfApp11 CMS 통합 관리 시스템

## 개요
WpfApp11은 다양한 디바이스(PC, 프로젝터, 릴레이, PDU 등)의 전원 제어, 파일 관리(FTP), VNC 원격 제어, 스케줄링 등 통합 관리를 지원하는 WPF 기반 윈도우 데스크탑 애플리케이션입니다.

## 주요 기능
- **전원 제어**: PC, 프로젝터(PJLINK, DLP), 릴레이, PDU의 전원 ON/OFF/REBOOT 및 상태 체크
- **스케줄 관리**: 요일별 전원 ON/OFF 시간 설정, 전체/개별 디바이스 스케줄링
- **파일 관리(FTP)**: FTP 서버와의 파일 업로드/다운로드, 폴더/파일 생성, 이름 변경, 삭제 등
- **VNC 원격 제어**: VNC를 통한 PC 원격 접속 및 제어
- **UI/UX**: 드래그&드롭 기반의 디바이스 배치, 직관적인 그리드 UI, 팝업 및 컨텍스트 메뉴 지원
- **로그 관리**: 전원/에러/일반 로그 파일 자동 기록 및 뷰어 제공(F1 단축키)

## 설치 및 실행 방법
1. **필수 환경**
   - Windows 10 이상
   - .NET Framework 4.7.2 이상
2. **빌드 및 실행**
   - Visual Studio에서 `WpfApp11.sln` 솔루션을 열고 빌드 후 실행
   - 또는 빌드된 실행 파일(`bin/Release` 또는 `bin/Debug`)을 직접 실행
3. **FTP 서버 설치(선택)**
   - `c:\exe` 폴더에 `Setup-IIS-FTP.ps1` 복사
   - PowerShell(관리자 권한)에서 아래 명령 실행:
     ```
     Set-ExecutionPolicy Unrestricted
     cd c:\exe
     .\Setup-IIS-FTP.ps1
     ```
   - IIS에서 FTP 사이트 추가 및 계정(ftpuser/1) 생성

## 사용법
- **디바이스 추가/삭제**: 그리드 빈 공간 우클릭 또는 더블클릭 → 장비 추가/삭제 메뉴
- **전원 제어**: 전체/개별 디바이스 ON/OFF/REBOOT 버튼 클릭
- **스케줄 설정**: 자동 전원 관리 메뉴에서 요일별 시간 및 토글 설정
- **파일 관리**: 파일관리 메뉴에서 FTP 서버와 로컬 간 파일/폴더 이동, 생성, 이름 변경, 삭제 등
- **VNC 제어**: VNC ON 설정 후 원격 제어 기능 사용
- **로그 확인**: F1 키로 로그 뷰어 창 열기

## 주요 파일 및 폴더 설명
- `MainWindow.xaml/cs` : 메인 UI 및 전체 로직
- `UserControls/` : 디바이스, 파일 탐색기 등 주요 컨트롤
- `Helpers/` : 전원/로그/프로토콜 등 각종 헬퍼 클래스
- `App.xaml/cs` : 앱 진입점 및 중복 실행 방지
- `settings.json`, `itemConfig.json` : 환경설정 및 디바이스 설정 파일(자동 생성)
- `Log/` : 각종 로그 파일 저장 폴더

## 주의사항 및 팁
- **설정 파일이 없을 경우 자동 생성됩니다.**
- **전원 제어 순서**
  - ON: 릴레이(PDU) → PDU → 프로젝터 → PC
  - OFF: PC → 프로젝터 → PDU → 릴레이(PDU)
- **릴레이는 상태체크를 하지 않으며, PDU는 상태체크를 수행합니다.**
- **설정 파일 네이밍 규칙**
  - 예시: `ProgressDuration`, `StatusCheckInterval` 등 카멜케이스 사용
- **로그 파일은 실행 경로의 Log 폴더에 일자별로 저장됩니다.**
